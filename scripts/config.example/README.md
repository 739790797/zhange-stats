# 站点配置模板（脚本资源）

`install` / `run` / `restart` / `update` 与应用启动都会对照这里，把**缺失字段**写入安装根 `config/`（gitignore，权限建议目录 700、文件 600）。

- 不会覆盖用户已有的值（含密钥）。嵌套对象按键填缺；列表整段以用户为准，不按元素合并。
- 不会从模板新建 `database.json`（安装向导负责选库）；已有的 `database.json` 仍会补缺失键。
- 每个 JSON 有 `_version`。改了该文件的字段后把 `_version` 加 1，存量安装下次启动或跑脚本会补上新键。

真实 `config/` 不要提交。
